Built for teams. Free forever.

Every collaboration, sync, and mobile feature included out of the box.

Live Request Remote & 1-Click Rejoin

Share active SSH sessions in Team Vaults with View or Control access while SSH stays 100% on your device.

  • 1-Click Rejoin
  • Live participant avatars

02 // Admin Portal Gateway Web

Gateway Web Admin Console

Manage users, Team Vault roles, and monitor online devices and active SSH sessions in real time.

  • Zero-knowledge storage
  • Live presence
  • Audit logs

Auto-Online & Offline Fallback

Switches to local encrypted storage when offline and syncs queued changes automatically on reconnect.

Keep-Alive & Focus Mode

Native SSH & SFTP Browser

Fast russh terminal with split panes, SFTP file transfers, and ED25519/RSA key management.

// Self-Host

Deploy your Gateway in one command.

Works on Linux and macOS. Sets up PostgreSQL, Gateway API, and Web Console automatically.

Quick Install scripts/install.sh

Run on your server or Mac:

curl -fsSL https://raw.githubusercontent.com/wisnu-w/OpenTermius/main/scripts/install.sh | bash

Or use an external PostgreSQL database (such as Supabase):

DATABASE_URL="postgres://user:pass@host:5432/postgres?sslmode=require" curl -fsSL https://raw.githubusercontent.com/wisnu-w/OpenTermius/main/scripts/install.sh | bash
