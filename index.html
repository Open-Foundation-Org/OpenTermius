// Exclusive Architecture

Built for engineers who refuse subscription lock-in.

Every collaboration, administration, and mobile persistence capability is engineered into the open-source core.

01 // Zero-SSH Blind Binary Relay WebSocket ArrayBuffer

Live Request Remote, 1-Click Rejoin & Typing Telemetry

Unlike bastion proxies that terminate SSH on a central server, OpenTermius keeps the SSH connection 100% native on the host device via Rust russh. When teammates in a shared Team Vault request View-Only or Control access, the Gateway relays raw PTY binary frames with sub-millisecond overhead.

  • 1-Click Rejoin without re-requesting
  • Circular live participant avatars
  • Real-time "{User} is typing..." pill
  • Auto-close & revoke when host stops sharing
02 // Self-Hosted Control Plane Svelte 5 + Go 1.24

Gateway Web Admin Console

Manage your entire team from a dedicated web dashboard. Provision accounts, create shared Team Vaults with Owner, Admin, and Member roles, inspect live online devices, and see active SSH sessions across your organization in real time.

  • Zero-knowledge vault storage
  • Auto-detected API origin & port
  • Session audit logs
03 // Continuity AES-256-GCM

Auto-Online & Offline Local Fallback

An 8-second presence heartbeat seamlessly transitions between Online · Gateway and Offline · Local. Offline edits queue locally and sync automatically when your gateway is reachable again.

04 // Mobile Precision Android & Tablet

Foreground Keep-Alive & Focus Mode

Android Foreground Service (PARTIAL_WAKE_LOCK) + 15s SSH keep-alives prevent disconnects when your screen locks. Includes 1-tap Focus Mode, overflow ⋮ menu, 2x7 Termux keys, and unbuffered IME streaming.

05 // Native Binary <10 MB Bundle

In-Memory Rust PTY & SFTP Browser

Powered by Tauri v2, russh, and russh-sftp. Browse remote files, upload/download, split terminal panes horizontally or vertically, and manage ED25519/RSA keys with zero local listening ports.

// 1-Command Deployment

Deploy your Gateway in 60 seconds.

Supports Ubuntu, Debian, Fedora, RHEL/Alma/Rocky, Arch, Alpine, and macOS. Automatically detects existing PostgreSQL servers, configures pg_hba.conf, resolves port conflicts, builds the Go API + Web Console, and registers systemd services.

Universal Installer (Interactive DB & Port Detection) scripts/install.sh

Paste into your VPS or macOS terminal:

curl -fsSL https://raw.githubusercontent.com/wisnu-w/OpenTermius/main/scripts/install.sh | bash

Or connect directly to an existing managed PostgreSQL database (Supabase, Neon, RDS) with TLS:

DATABASE_URL="postgres://user:pass@host:5432/postgres?sslmode=require" curl -fsSL https://raw.githubusercontent.com/wisnu-w/OpenTermius/main/scripts/install.sh | bash
