Deploy your Gateway in one command

Runs on Linux and macOS. Installs PostgreSQL, the Gateway API, and the Web Admin Console automatically.

Run on your server or Mac:

curl -fsSL https://raw.githubusercontent.com/Open-Foundation-Org/OpenTermius/main/scripts/install.sh | bash

Or connect an external PostgreSQL database:

DATABASE_URL="postgres://user:pass@host:5432/postgres?sslmode=require" curl -fsSL https://raw.githubusercontent.com/Open-Foundation-Org/OpenTermius/main/scripts/install.sh | bash

macOS Gatekeeper note

If macOS says OpenTermius is damaged on an un-notarized build, move OpenTermius.app to Applications and run once:

xattr -cr /Applications/OpenTermius.app

Windows SmartScreen and privacy

If SmartScreen prompts on first install, choose More info then Run anyway.
