The SSH client

OpenTermius is a free alternative to Termius. Connect to your servers with native SSH and SFTP, and keep your hosts in encrypted vaults on your own server. No paywall, no subscription.

Build it yourself

Run your own gateway

The gateway stores encrypted vaults and syncs your devices. You need Go 1.24+, Node.js 22+, and PostgreSQL 15+.

# 1. Get the code and set up your environment
git clone https://github.com/wisnu-w/OpenTermius.git
cd OpenTermius
cp .env.example .env

# 2. Create the database tables
psql -d opentermius -f migrations/000001_init.up.sql

# 3. Start the gateway API (port 8080)
cd backend && go run cmd/api/main.go

# 4. Start the web console to manage users and teams (port 5174)
cd ../gateway-web && npm install && npm run dev

Then open the app, choose Connect to Gateway, and enter your gateway URL. Read the README for full setup steps.
